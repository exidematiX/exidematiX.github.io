## 使用方法与三遍刷法

- **第一遍（约 1 周）**：看题解写代码，只求理解模板与识别信号，每个专题 1~2 小时。
- **第二遍（约 1 周）**：关题解限时 20 分钟重写，卡住的题打勾标记。
- **第三遍（约 3 天）**：只做打勾的题，并默写本文件里的模板，直到不看书能写。
- 每题只记三件事：**识别信号 / 关键思路 / 易错点**。
- 拒绝收藏一堆题解，固定看 1 篇官方题解 + 1 篇高赞。

## 哈希

**识别信号**：需要「查找某个值是否出现过」「去重」「分组」「O(n) 换 O(1) 查询」。

**模板**

```cpp
// 边遍历边查表（两数之和）
unordered_map<int, int> mp;
for (int i = 0; i < n; ++i) {
    if (mp.count(target - nums[i])) return {mp[target - nums[i]], i};
    mp[nums[i]] = i;
}
```

**题目清单**

- [ ] 1. 两数之和：一遍哈希，存「值 → 下标」。
- [ ] 49. 字母异位词分组：排序后的字符串当 key，`vector<string>` 当 value。
- [ ] 128. 最长连续序列：全部丢进 `unordered_set`，只从「没有前驱 `x-1`」的数开始向后数。

**易错点**

- 128 必须判 `x-1` 是否存在，否则退化成 O(n²)。
- 49 用计数排序数组当 key 可比字符串排序更快。

## 双指针

**识别信号**：数组有序、需要原地修改、两数/三数之和、装水面积类。

**模板**

```cpp
// 左右对撞：有序数组两数之和
int l = 0, r = n - 1;
while (l < r) {
    int s = nums[l] + nums[r];
    if (s == target) { /* 记录 */ }
    else if (s < target) ++l;
    else --r;
}

// 快慢指针：原地移除 / 移动元素
int slow = 0;
for (int fast = 0; fast < n; ++fast)
    if (nums[fast] != 0) nums[slow++] = nums[fast];
```

**题目清单**

- [ ] 283. 移动零：快慢指针，非零前移，末尾补零。
- [ ] 11. 盛最多水的容器：左右指针，每次移动**较短**的一侧，面积 = `min(h[l],h[r]) * (r-l)`。
- [ ] 15. 三数之和：排序 + 固定一个数 + 双指针，跳过重复元素。
- [ ] 42. 接雨水：左右双指针 + 维护 `leftMax/rightMax`，每格贡献 `min(leftMax,rightMax) - height[i]`。

**易错点**

- 15 去重要在「固定数」和「双指针移动」两处都跳过相同值。
- 42 双指针法移动较矮侧后立即结算，别等循环结束。

## 滑动窗口

**识别信号**：连续子数组 / 子串，求最长、最短、满足某条件的窗口。

**模板**

```cpp
int left = 0;
unordered_map<char, int> win;
for (int right = 0; right < n; ++right) {
    // 1. 右指针入窗
    win[s[right]]++;
    // 2. 不合法时收缩左指针
    while (/* 窗口不合法 */) {
        // 更新计数
        win[s[left]]--;
        ++left;
    }
    // 3. 更新答案
    ans = max(ans, right - left + 1);
}
```

**题目清单**

- [ ] 3. 无重复字符的最长子串：窗口内无重复，出现重复时收缩左指针。
- [ ] 438. 找到字符串中所有字母异位词：固定长度窗口，比较字母计数数组是否相等。

**易错点**

- 区分「窗口长度固定」和「窗口长度可变」，两者的收缩条件不同。
- 字符用 `int cnt[26]` 比 `unordered_map` 快很多。

## 子串

**识别信号**：子数组和、窗口最值、最短覆盖。

**模板**

```cpp
// 前缀和求「和为 K 的子数组」
unordered_map<int, int> pre{{0, 1}};
int sum = 0, ans = 0;
for (int x : nums) {
    sum += x;
    if (pre.count(sum - k)) ans += pre[sum - k];
    pre[sum]++;
}
```

**题目清单**

- [ ] 560. 和为 K 的子数组：前缀和 + 哈希，初始化 `{0,1}`。
- [ ] 239. 滑动窗口最大值：单调递减双端队列，队头即最大值，出队时弹出越界下标。
- [ ] 76. 最小覆盖子串：可变窗口 + 计数，`valid` 记录已满足种类数。

**易错点**

- 560 初始化 `pre[0]=1` 处理「从下标 0 开始」的子数组。
- 239 队列存**下标**，不是值。

## 链表

**识别信号**：涉及指针操作、判环、倒数、排序。

**通用技巧**

- 加**哨兵节点** `dummy`，统一处理头节点被删/改的情况。
- **反转链表**三指针：`prev / cur / next`。
- **快慢指针**：找中点、判环、找倒数第 k。
- 递归与迭代都掌握，面试常追问。

**模板**

```cpp
// 反转链表
ListNode* reverse(ListNode* head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode* nxt = cur->next;
        cur->next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}
```

**题目清单**

- [ ] 160. 相交链表：A 走完接 B、B 走完接 A，相遇即交点。
- [ ] 206. 反转链表：三指针迭代。
- [ ] 234. 回文链表：快慢找中点 + 反转后半 + 比较。
- [ ] 141. 环形链表：快慢指针相遇即有环。
- [ ] 142. 环形链表 II：相遇后一指针回头，两指针同速再相遇即入环点。
- [ ] 21. 合并两个有序链表：哨兵 + 比较尾插。
- [ ] 2. 两数相加：逐位相加，处理进位。
- [ ] 19. 删除倒数第 N 个：哑节点 + 快指针先走 N+1 步。
- [ ] 24. 两两交换：迭代或递归。
- [ ] 25. K 个一组翻转：分组反转 + 连接前后段。
- [ ] 138. 随机链表的复制：哈希存「原 → 新」，或原地拼接拆分。
- [ ] 148. 排序链表：归并排序（快慢找中点 + 合并）。
- [ ] 23. 合并 K 个升序链表：分治两两合并，或优先队列。
- [ ] 146. LRU 缓存：哈希 + 双向链表，手动维护 `head/tail`。

**易错点**

- 146 用 C++ 时注意 `list` 迭代器失效问题，最好手写双向链表或存 `list::iterator`。
- 138 克隆前先建好所有新节点再连 `random`。

## 二叉树

**识别信号**：树结构遍历、求深度/路径/祖先、BST 性质、构造树。

**递归三要素**

1. 参数与返回值是什么？
2. 单层逻辑做什么？
3. 终止条件是什么？

**模板**

```cpp
// 前序/中序/后序：只改访问位置
void dfs(TreeNode* root) {
    if (!root) return;
    // 前序
    dfs(root->left);
    // 中序
    dfs(root->right);
    // 后序
}

// 层序 BFS
queue<TreeNode*> q; q.push(root);
while (!q.empty()) {
    int sz = q.size();
    while (sz--) {
        auto* node = q.front(); q.pop();
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
```

**题目清单**

- [ ] 94. 二叉树的中序遍历：递归 / 显式栈 / Morris。
- [ ] 104. 二叉树的最大深度：`1 + max(dfs(l), dfs(r))`。
- [ ] 226. 翻转二叉树：交换左右子树后递归。
- [ ] 101. 对称二叉树：比较 `l->left` 与 `r->right`、`l->right` 与 `r->left`。
- [ ] 543. 二叉树的直径：后序求左右深度和，全局更新 `l + r`。
- [ ] 102. 二叉树的层序遍历：BFS 分层收集。
- [ ] 108. 有序数组转 BST：取中点做根，递归左右。
- [ ] 98. 验证二叉搜索树：递归带上下界，或用中序递增判断。
- [ ] 230. BST 第 K 小的元素：中序遍历到第 K 个。
- [ ] 199. 二叉树右视图：层序取每层最后一个。
- [ ] 114. 展开为链表：前序遍历后重连，或后序原地展开。
- [ ] 105. 前序 + 中序构造二叉树：哈希定位中序根，递归分左右。
- [ ] 437. 路径总和 III：前缀和 + 回溯，`count[sum - target]`。
- [ ] 236. 最近公共祖先：后序，某子树返回非空即为祖先。
- [ ] 124. 最大路径和：后序，单边贡献 `max(0, child)`，全局更新双边和。

**易错点**

- 98 不能只比较父子节点，要用上下界（或中序）。
- 124 返回给父节点时只能选一边，全局答案才可左右都取。

## 图论

**识别信号**：网格连通块、拓扑排序、前缀树。

**模板**

```cpp
// 网格 DFS（岛屿数量）
void dfs(vector<vector<char>>& g, int i, int j) {
    if (i < 0 || i >= g.size() || j < 0 || j >= g[0].size() || g[i][j] != '1') return;
    g[i][j] = '0';
    dfs(g, i+1, j); dfs(g, i-1, j); dfs(g, i, j+1); dfs(g, i, j-1);
}

// 拓扑排序（课程表）
queue<int> q;
for (int i = 0; i < n; ++i) if (inDeg[i] == 0) q.push(i);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) if (--inDeg[v] == 0) q.push(v);
}
```

**题目清单**

- [ ] 200. 岛屿数量：DFS/BFS 淹没陆地。
- [ ] 994. 腐烂的橘子：多源 BFS，按层计时。
- [ ] 207. 课程表：拓扑排序，出队数量等于课程数则无环。
- [ ] 208. 实现 Trie：`children[26]` + `isEnd`。

**易错点**

- 994 初始腐烂橘子全部入队；结束时若有新鲜橘子返回 -1。
- Trie 用数组比 `unordered_map` 快，注意 `nullptr` 初始化。

## 回溯

**识别信号**：求所有组合/排列/子集、需要枚举全部方案、带约束的搜索。

**模板**

```cpp
void backtrack(参数) {
    if (满足终止条件) { ans.push_back(path); return; }
    for (选择 : 本层可选集合) {
        做选择;
        backtrack(下一层);
        撤销选择;
    }
}
```

**题目清单**

- [ ] 46. 全排列：`used` 标记，排列每次从头选。
- [ ] 78. 子集：每个节点都收集结果，用 `start` 避免重复。
- [ ] 17. 电话号码的字母组合：按位索引，回溯拼接。
- [ ] 39. 组合总和：可重复选，`start` 不前进；注意剪枝 `sum > target` 返回。
- [ ] 22. 括号生成：记录 `left/right` 数量，`left < n` 可加左，`right < left` 可加右。
- [ ] 79. 单词搜索：网格 DFS + 原地标记访问。
- [ ] 131. 分割回文串：`start` 位置枚举切点 + 回文判断。
- [ ] 51. N 皇后：逐行放置，用列/主对角/副对角线集合判冲突。

**易错点**

- 组合类去重要么用 `start`，要么排序后 `if (i>start && nums[i]==nums[i-1]) continue;`。
- 79 回溯完必须恢复字符。

## 二分查找

**识别信号**：有序、旋转有序、找边界、找第 K 小、O(log n) 要求。

**模板**

```cpp
// 左闭右闭
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (nums[mid] == target) return mid;
    else if (nums[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}

// 找左边界
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid;
}
```

**题目清单**

- [ ] 35. 搜索插入位置：标准二分返回 `lo`。
- [ ] 74. 搜索二维矩阵：整体当作一维有序数组，下标换算。
- [ ] 34. 查找第一个和最后一个位置：分别二分找左右边界。
- [ ] 33. 搜索旋转排序数组：判断 `mid` 落在哪段有序区，再决定收缩方向。
- [ ] 153. 旋转数组最小值：`nums[mid]` 与 `nums[hi]` 比较。
- [ ] 4. 寻找两个正序数组的中位数：对较短数组二分分割线。

**易错点**

- 求 `mid` 用 `lo + (hi-lo)/2`，防止溢出。
- 旋转数组先判断「哪半边有序」，再判断 target 是否落在有序半边。

## 栈

**识别信号**：括号匹配、下一个更大/更小、表达式解析、字符串解码。

**模板**

```cpp
// 单调栈（每日温度）
stack<int> stk;
for (int i = 0; i < n; ++i) {
    while (!stk.empty() && nums[i] > nums[stk.top()]) {
        ans[stk.top()] = i - stk.top();
        stk.pop();
    }
    stk.push(i);
}
```

**题目清单**

- [ ] 20. 有效的括号：左括号入栈，右括号匹配栈顶。
- [ ] 155. 最小栈：辅助栈同步存当前最小值。

- [ ] 84. 柱状图中最大的矩形：单调递增栈 + 两侧加哨兵 0。

**易错点**

- 84 首尾补 `0` 可省去边界判断。
- 20 注意「右括号但栈为空」也要判错。

## 动态规划

**识别信号**：求最优值/方案数、重叠子问题、有「选与不选」。

**解题四步**

1. 定义 `dp` 数组含义（下标 + 值）。
2. 写转移方程。
3. 初始化。
4. 确定遍历顺序。

**模板**

```cpp
// 01 背包（分割等和子集：能否凑出 target）
vector<bool> dp(target + 1, false);
dp[0] = true;
for (int x : nums)
    for (int j = target; j >= x; --j)   // 01 背包倒序
        dp[j] = dp[j] || dp[j - x];

// 完全背包（零钱兑换）
vector<int> dp(amount + 1, amount + 1);
dp[0] = 0;
for (int x : coins)
    for (int j = x; j <= amount; ++j)   // 完全背包正序
        dp[j] = min(dp[j], dp[j - x] + 1);
```

**题目清单**

- [ ] 70. 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`。
- [ ] 118. 杨辉三角：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`。
- [ ] 198. 打家劫舍：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。
- [ ] 279. 完全平方数：完全背包，物品为 `1²,2²,...`。
- [ ] 322. 零钱兑换：完全背包求最少硬币数。
- [ ] 139. 单词拆分：`dp[i]` 表示前 i 字符可拆，枚举切点。
- [ ] 300. 最长递增子序列：`dp[i]` 以 i 结尾的 LIS，O(n²)；进阶贪心 + 二分 O(n log n)。
- [ ] 152. 乘积最大子数组：同时维护 `maxDp / minDp`。
- [ ] 416. 分割等和子集：01 背包可行性。
- [ ] 32. 最长有效括号：`dp[i]` 表示以 i 结尾的最长有效长度，注意 `()` 与 `))` 两种转移。

**易错点**

- 01 背包倒序遍历容量，完全背包正序。
- 152 因负数会翻转最大最小，必须同时维护。

## 多维动态规划

**识别信号**：两个序列、二维网格路径、区间 DP。

**题目清单**

- [ ] 62. 不同路径：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`，可滚动数组。
- [ ] 64. 最小路径和：在 62 基础上取 `min` 加当前格。
- [ ] 5. 最长回文子串：区间 DP，或中心扩展 O(n²)。
- [ ] 1143. 最长公共子序列：`text1[i]==text2[j]` 则 `dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])`。
- [ ] 72. 编辑距离：增删改三选一，`dp[i][j]` 前 i 转前 j 的最少操作。

**易错点**

- 5 中心扩展要分别处理奇偶长度。
- 1143 与 72 的下标从 1 开始，避免边界判断。

## 技巧

**识别信号**：只出现一次、多数元素、原地排序、找重复数。

**题目清单**

- [ ] 136. 只出现一次的数字：全部异或，`a ^ a = 0`。
- [ ] 169. 多数元素：Boyer-Moore 投票法。
- [ ] 75. 颜色分类：三指针（荷兰国旗问题），`0` 前放、`2` 后放。
- [ ] 31. 下一个排列：从右找第一个升序对 + 交换 + 反转后缀。
- [ ] 287. 寻找重复数：快慢指针找环入口，或二分答案。

**易错点**

- 75 交换 `2` 到后面后，当前指针不能前进（换来的可能是 `0`）。
- 287 不能改数组，位运算可处理但快慢指针更通用。
