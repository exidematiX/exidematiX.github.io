C++

深拷贝与浅拷贝

  • 浅拷贝是只复制对象的值而不进行资源的复制，共享一块内存，容易造成一个对象修改值后另一个对象值也改变；一个对象删除后另一个对象的指针成野指针
  • 深拷贝是同时进行资源的复制，开辟一块新的内存，互不影响

多态的实现

  • 编译时多态：函数重载、运算符重载
  • 运行时多态：虚函数（虚函数指针 + 虚函数表，表在只读数据段）
面试官拷打的不是知识点，是你有没有真的踩过。

智能指针

智能指针主要解决 内存泄露、野指针、悬空指针 三类问题……

struct FrameInput {

C#

mono 和 IL2CPP

  • mono：编译为 IL → JIT 即时编译机器码。优点：无需额外编译、支持运行时动态加载、跨平台。缺点：性能不如预编译、IL 易反编译
  • IL2CPP：IL → C++ → 机器码。优点：高性能、安全性高。缺点：编译耗时、无法动态支持
